Using highlightjs in Angular

Purpose

  • As an angular developer, how to create a directive that shows a code snippet from https://gist.github.com in your angular application. It should highlight syntax, display line number and copy button.
  • I tried to use the package ngx-highlightjs. But I cannot add more plugin copy button and customize fromLine and toLine in this library. So, I developed another way to implement these feature without this package.

Result
